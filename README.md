# Text Analyzer

CS 250 Final Project (Fall 2026), SFBU.

A Python program (Google Colab notebook) that reads a `.txt` file and answers:
**"Is my text too long, too repetitive, or too slow to start?"**

It shows word and sentence counts, speaking time, the first 30 words, the most common words
(with a bar chart), and simple tips.

## How to run
1. Open `Text_Analyzer.ipynb` in Google Colab.
2. Run all cells. The notebook creates two sample texts and analyzes them.
3. For your own text, upload a `.txt` file and run `main("your_file.txt")`.

## Files
- `text_analyzer.py`: the same program as a plain Python script (`python text_analyzer.py`)
- `Text_Analyzer.ipynb`: the code, tests, results, and AI log
- `sample_good.txt`, `sample_slow.txt`: sample texts used for testing
